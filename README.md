FaderDeck - app to control volume(or somthing another) of other apps by using a midi divices 

## build

Since there is currently no full release for download, you can compile it yourself.

### Here a full guide

1. Download the project (from this page or with git)
```
git clone https://github.com/gLeknya/FaderDeck.git
```
2. You need to download Node.js
> https://nodejs.org/en/download

3. Open project folder in terminal and write this commands (one by one!)
```
npm init -y
npm install
```

4. Done! You ready to start the app
```
npm start
```

have fun!
