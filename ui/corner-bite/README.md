# corner-bite

Библиотека для создания и плавной анимации фигур со скруглёнными **выпуклыми** и **вогнутыми** («прикушенными») углами в HTML/CSS/JS.

Создана для десктопных и веб-интерфейсов (панели, карточки, плееры, сайдбары, вкладки), где блоки соединяются скруглёнными переходами на стыках и анимируются без скачков формы.

- **0 зависимостей** в рантайме.
- **Чистый JavaScript (ES Modules)**, работает в браузере как есть без сборщиков и транспиляторов.
- **Встроенные тесты `node --test`**.
- Строго 4-слойная архитектура: Core (геометрия) не зависит от DOM/браузера.

## Быстрый старт

### 1. Установка / Подключение

Так как библиотека написана на чистых ES-модулях, её можно импортировать напрямую:

```javascript
import { attach, joinShapes, glue, setGradient, animate, buildPath } from './src/index.js';
```

### 2. Скругление одного элемента или произвольного полигона (`attach`)

```javascript
const box = document.getElementById('my-box');

const controller = attach(box, {
  rects: [
    { x: 0, y: 0, w: 200, h: 100 },
    { x: 100, y: 100, w: 100, h: 80 }
  ],
  radius: 16,        // Радиус для выпуклых углов
  concaveRadius: 16, // Радиус для вогнутых углов (по умолчанию равен radius)
  mode: 'svg'        // 'svg' (по умолчанию) или 'clip'
});

// Обновление радиуса:
controller.setRadius(24);

// Удаление при размонтировании:
controller.destroy();
```

### 3. Объединение двух независимых DOM-элементов (`joinShapes`)

Складывает прямоугольники реальных элементов и строит **единый общий контур** с вогнутыми скруглениями на стыке:

```html
<div class="panel-container" style="position: relative;">
  <div id="sidebar" style="background: transparent;">Меню</div>
  <div id="player" style="background: transparent;">Плеер</div>
</div>
```

```javascript
import { joinShapes } from './src/index.js';

const shape = joinShapes([sidebar, player], {
  radius: 20,
  concaveRadius: 20,
  follow: true // Автоматически отслеживает CSS transitions / WAAPI анимации
});
```

### 4. Автоматическая сборка по атрибутам (`glue`)

```html
<div id="app" style="position: relative;">
  <div data-concave-part>Панель</div>
  <div data-concave-part>Вкладка</div>
</div>
```

```javascript
import { glue } from './src/index.js';

const g = glue('#app', { radius: 16 });

// Если элементы добавились динамически:
g.refresh();
```

## Сравнение режимов рендеринга

| Режим | Как работает | Плюсы | Ограничения |
|---|---|---|---|
| **`mode: 'svg'`** *(по умолчанию)* | Абсолютно позиционированный `<svg>` под контентом (`pointer-events: none`) с `<path>`. | Идеально для градиентов, обводок, теней (`filter: drop-shadow`), изменения яркости всей фигуры. | Фон элементов должен быть прозрачным (`transparent`). |
| **`mode: 'clip'`** | Устанавливает `clip-path: path('...')` непосредственно на элемент. | Обрезает контент внутри элемента, поддерживает `conic-gradient`, фоновые изображения и `backdrop-filter`. | Собственные `border` и `box-shadow` обрезаются браузером; тень делается через `filter: drop-shadow` на родителе; обводка требует отдельного слоя. |
| **`mode: 'patches'`** | На стыках блоков рисуются маленькие вогнутые накладки поверх элементов. | Элементы сохраняют собственные непрозрачные CSS-фоны. | Только сплошные цвета (без прозрачности, градиентов и `backdrop-filter`). Цвет задаётся опцией `patchColor` или берётся из фона первого элемента. |

## Стилизация и CSS-переменные

В режиме `svg` стилизация слоя выполняется штатными CSS-переменными:

```css
.corner-bite-layer {
  --cb-fill: #3b82f6;           /* Цвет заливки (по умолчанию currentColor) */
  --cb-stroke: #60a5fa;         /* Цвет обводки (по умолчанию none) */
  --cb-stroke-width: 2px;       /* Толщина обводки (по умолчанию 0) */
  filter: drop-shadow(0 12px 24px rgba(0, 0, 0, 0.4));
  transition: filter 0.2s ease;
}
```

### Градиенты (`setGradient`)

Хелпер создаёт `<defs>` с уникальным `id` и назначает градиент в `--cb-fill`:

```javascript
import { setGradient } from './src/index.js';

// Линейный градиент с углом
setGradient(controller, {
  type: 'linear',
  angle: 135,
  stops: ['#ec4899', '#8b5cf6', '#3b82f6']
});

// Радиальный градиент
setGradient(controller, {
  type: 'radial',
  stops: [
    { offset: 0, color: '#38bdf8', opacity: 1 },
    { offset: 1, color: '#0f172a', opacity: 0.8 }
  ]
});
```

## Анимация и планировщик

### 1. Встроенный интерполятор (`animate`)

Функция `animate` интерполирует **числовые координаты геометрии** (а не SVG-строку), пересчитывая правильный путь каждый кадр.

```javascript
import { animate } from './src/index.js';

const anim = animate(controller, [
  { x: 50, y: 50, w: 300, h: 200 }
], {
  duration: 400,
  easing: 'easeInOutCubic', // 'linear' | 'easeInCubic' | 'easeOutCubic' | 'easeInOutCubic' | (t) => number
  onUpdate: (geo) => console.log('Current:', geo)
});

// Отмена анимации при необходимости:
// anim.cancel();

// Ожидание завершения:
await anim.finished;
```

### 2. Внешние анимационные движки (GSAP, Anime.js, requestAnimationFrame)

Метод `controller.update(newGeometry)` дешёвый, не содержит побочных эффектов и безопасно вызывается на каждый кадр:

```javascript
gsap.to(rect, {
  x: 200,
  y: 150,
  duration: 0.5,
  onUpdate: () => controller.update([rect])
});
```

### 3. Автоматическое слежение (`follow`)

В `joinShapes`:
- `follow: false` (по умолчанию): перерисовка по `ResizeObserver` и `window.resize`.
- `follow: true`: слушает события `transitionrun`, `animationstart` и проверяет `element.getAnimations()`, автоматически включая покадровое чтение позиций только на время анимации.
- `follow: 'always'`: непрерывный RAF-луп (для анимаций, управляемых внешними скриптами).

## Привязка к пикселям (`snap`)

Параметр `snap: true` (включен по умолчанию) устраняет субпиксельное размытие и артефакты:
- **В покое (idle)**: координаты скругляются до $1 / \text{devicePixelRatio}$.
- **Во время анимации**: используются дробные координаты для идеальной плавности.
- **Через 120 мс** после прекращения изменений выполняется один финальный рендер с привязкой к физическим пикселям экрана.
- Смена зума (`devicePixelRatio`) автоматически вызывает перерисовку.

## Справочник API

### Ядро (Core)

#### `buildPath(input, options)`
Строит SVG path `d` из полигона `[{x, y, r?}]` или списка прямоугольников `[{x, y, w, h}]`.
- **`input`**: `Point[] | Rect[] | Point[][]`
- **`options`**:
  - `radius`: радиус выпуклых углов (по умолчанию 0).
  - `concaveRadius`: радиус вогнутых углов (по умолчанию равен `radius`).
  - `smoothing`: зарезервирован для будущей континуальной кривизны (пока no-op).
  - `precision`: количество знаков после запятой (по умолчанию 3).
  - `bleed`: расширение прямоугольников перед объединением в px (по умолчанию 0).

#### `unionRects(rects)`
Выполняет 2D булево объединение прямоугольников. Возвращает массив замкнутых контуров `Array<Array<{x, y}>>` с удалёнными коллинеарными вершинами и отсортированных по обходу по часовой стрелке (CW).

#### `roundedUnion(rects, options)`
Объединяет прямоугольники и сразу строит скруглённую SVG-строку `d`.

### DOM

#### `attach(element, options)`
Привязывает скруглённую форму к одному элементу.
Возвращает контроллер:
- `update(geometry)`: обновить координаты.
- `setRadius(radius, concaveRadius?)`: изменить радиус.
- `getPath()`: синхронно получить текущую строку `d`.
- `destroy()`: идемпотентная очистка (удаляет слой/стили).
- `svgElement`, `pathElement`: ссылки на DOM-элементы.

#### `joinShapes(elements, options)`
Измеряет реальные прямоугольники переданных элементов относительно ближайшего общего позиционированного предка и строит единый общий контур.
- Опции: `radius`, `concaveRadius`, `mode` (`'svg'|'clip'|'patches'`), `patchColor`, `follow` (`false|true|'always'`), `snap`, `bleed`.

#### `glue(container, options)`
Находит элементы с `data-concave-part` внутри контейнера и вызывает `joinShapes`.
- Метод `refresh()`: пересканирует DOM.

## Decisions (Архитектурные решения)

1. **Точная дискретная сеточная декомпозиция для `unionRects`**:
   Вместо геометрических операций с плавающей точкой и epsilon-сравнений отрезков, объединение прямоугольников раскладывает плоскость на элементарные прямоугольные ячейки через уникальные координаты X и Y. Это гарантирует 100% надёжность, полное отсутствие самопересечений и корректную топологию контуров при любом взаимном расположении блоков.
2. **Непрерывность стыка и автоограничение вогнутого радиуса**:
   При сближении и отдалении блоков длина контакта $L$ между ними стремится к нулю. Чтобы исключить скачок формы («pop»), максимальный радиус вогнутого угла на стыке аппаратно ограничивается текущей длиной контакта ($r \le L_{contact}$). В результате при $L \to 0$ вогнутый угол плавно стягивается в ноль, и переход в режим двух отдельных блоков происходит совершенно незаметно для глаза.
3. **Фиксированная структура пути (`M L A ... Z`)**:
   Для контура из $N$ вершин строка `d` всегда содержит строго 1 команду `M`, $N$ команд `L`, $N$ команд `A` и 1 команду `Z`. При $r = 0$ дуга вырождается в нулевой отрезок (`A 0 0 0 0 1 x y`). Это позволяет браузерным движкам интерполировать пути напрямую без смены типов команд.
4. **Независимость ядра от DOM**:
   Все модули в `src/core/` не обращаются к `window`, `document` или `navigator`. Они могут выполняться на сервере (Node.js, SSR, Deno, Bun) и на воркерах.
5. **Дедупликация в общем планировщике**:
   Если для одной фигуры в течение одного кадра вызваны несколько обновлений, пересчёт контура происходит только один раз. При неизменившейся геометрии (с допуском $10^{-3}$) пересчёт пропускается.

## Ограничения и планы развития

- **Криволинейные стороны**: В текущей версии поддерживаются полигоны с прямолинейными сегментами. Архитектура слоя `fillet.js` вынесена в отдельную стратегию и подготовлена для добавления дуг Безье на сторонах.
- **Параметр `smoothing`**: Зарезервирован в опциях. В следующих версиях будет добавлен алгоритм непрерывной кривизны (squircle / superellipse, G2-непрерывность).
- **Gooey-эффект (мост через зазор)**: Планируется в виде отдельного режима соединения блоков на расстоянии.
- **Отверстия внутри фигур**: Будут поддержаны через чётность правила заливки `fill-rule="evenodd"`.
- **Повороты (`rotate`) элементов**: Поддерживаются `translate` и `scale`. Произвольные повороты в DOM-режиме требуют полноценного 2D-полигонального клиппинга произвольных углов.

## Демо-страница

Для запуска демонстрационной страницы используйте любой локальный веб-сервер (так как браузеры блокируют загрузку ES-модулей по протоколу `file://`):

```bash
# Через npx serve:
npx serve .

# Или через Python:
python -m http.server 8000
```

Откройте `http://localhost:8000/demo/index.html`.

Демо содержит 4 интерактивные сцены:
1. **Ступенчатая фигура**: эталонная форма из 3 прямоугольников (`x=232, y=84, w=153, h=224`, `x=232, y=150, w=425, h=238`, `x=108, y=308, w=484, h=198`).
2. **Стык двух блоков с анимацией**: панель и скользящий плеер с ползунком перекрытия и авто-анимацией.
3. **Стилизация**: линейные и радиальные градиенты, обводка, фильтры яркости и тени.
4. **Режим clip**: конический градиент и `backdrop-filter` на пёстром фоне.
