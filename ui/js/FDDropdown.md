# FDDropdown

Дропдаун без зависимостей. Плавно раскрывается, а выбранный пункт «переезжает»: в закрытом виде он стоит в шапке, при открытии спускается (или поднимается) на своё место в списке, а при выборе другого пункта тот уезжает в шапку.

- один файл `fd-dropdown.js`, CSS подключается сам
- любое количество пунктов, высота считается автоматически
- раскрытие вниз, вверх или `auto`
- клавиатура, `prefers-reduced-motion`, ARIA-роли
- ~14 КБ без минификации

## Подключение

В браузере:

```html
<script src="fd-dropdown.js"></script>
```

Через сборщик (Vite, webpack и т.п.) файл работает как CommonJS/UMD:

```js
import FDDropdown from './fd-dropdown.js';
// или
const FDDropdown = require('./fd-dropdown.js');
```

Нативные ES-модули в браузере без сборщика файл не импортируют, там нужен `<script>`. Создавать дропдаун нужно после того, как DOM готов (нужен `document.head` и контейнер).

## Быстрый старт

```html
<div id="midi" style="width: 240px"></div>

<script>
  const dd = new FDDropdown('#midi', {
    items: ['Turn off', 'SMC-Mixer', 'MIDIIN2 (SMC-Mixer)'],
    index: 1,
    onChange(value, d) {
      console.log(value, d.index, d.item);
    }
  });
</script>
```

Дропдаун занимает всю ширину контейнера. Либо задай ширину контейнеру, либо опцию `width`.

## Пункты

Пункт может быть примитивом или объектом:

```js
items: [
  'Turn off',                                        // value = 'Turn off'
  42,                                                // value = 42 (число остаётся числом)
  { label: 'MIDIIN2', value: 'midi2' },              // отдельное значение
  { label: 'Bluetooth', value: 'bt', disabled: true }, // нельзя выбрать
  { label: 'USB', value: 'usb', data: { id: 7 } }    // data доступна в d.item.data
]
```

Если у объекта нет `value`, значением станет `label`. Текст пункта вставляется как обычный текст (`textContent`), HTML внутри не работает, так что можно спокойно подставлять названия устройств и тому подобное.

## Опции конструктора

| Опция | Тип | По умолчанию | Описание |
|---|---|---|---|
| `items` | `Array` | `[]` | Список пунктов |
| `index` | `number` | `0` | Индекс выбранного пункта, `-1` для «ничего не выбрано» |
| `value` | любой | нет | Выбрать пункт по значению (строгое сравнение `===`), приоритетнее `index` |
| `placeholder` | `string` | `'Select…'` | Текст в шапке, когда ничего не выбрано |
| `direction` | `'down' \| 'up' \| 'auto'` | `'down'` | Куда раскрывается |
| `width` | `number \| string` | 100% контейнера | Число в px или любая CSS-ширина |
| `className` | `string` | нет | Дополнительный класс на корневом элементе |
| `onChange` | `function` | нет | `(value, detail)`, вызывается при смене выбора |
| `onOpen` | `function` | нет | `(value, detail)` |
| `onClose` | `function` | нет | `(value, detail)` |

`detail` содержит: `{ index, item, value, dropdown }`.

## Методы

Все методы, которые ничего не возвращают, возвращают сам объект, поэтому их можно цеплять.

| Метод | Описание |
|---|---|
| `setItems(items, { index, value })` | Заменить список. Если выбор не указан, выбирается первый пункт. Событие `change` не вызывается |
| `select(index, { silent })` | Выбрать по индексу. Недоступные пункты игнорируются. С `silent: true` без события |
| `setValue(value, { silent })` | То же, но по значению |
| `open()` / `close()` / `toggle()` | Управление раскрытием |
| `setDirection('down' \| 'up' \| 'auto')` | Сменить направление |
| `on(type, fn)` / `off(type, fn)` | Подписка на `'change'`, `'open'`, `'close'` |
| `destroy()` | Убрать элемент и слушатели |

## Свойства (только чтение)

| Свойство | Описание |
|---|---|
| `dd.value` | Значение выбранного пункта или `null` |
| `dd.index` | Индекс выбранного пункта или `-1` |
| `dd.item` | Объект выбранного пункта `{ label, value, disabled, data }` или `null` |
| `dd.isOpen` | Раскрыт ли сейчас |
| `dd.root` | Корневой DOM-элемент (`.fdd`) |

## События

Событие `change` приходит только когда выбор действительно изменился. При создании дропдауна оно не вызывается.

Подписаться можно тремя способами:

```js
// 1. опция
new FDDropdown('#a', { items, onChange: (value, d) => {} });

// 2. метод on
dd.on('change', (value, d) => {});

// 3. DOM-событие, оно всплывает, можно слушать на контейнере или document
document.addEventListener('fdd:change', e => {
  console.log(e.detail.value, e.detail.index, e.detail.dropdown);
});
```

DOM-события: `fdd:change`, `fdd:open`, `fdd:close`.

## Направление раскрытия

```js
new FDDropdown('#a', { items, direction: 'up' });
```

- `down`: шапка остаётся сверху, список растёт вниз
- `up`: шапка остаётся снизу, список растёт вверх, порядок пунктов сверху вниз не меняется
- `auto`: при каждом открытии сравнивает место над и под дропдауном в окне. Открывает вниз, если места хватает или сверху не просторнее. Учитывает только размер окна, а не прокручиваемые контейнеры

## Динамический список

Типичный случай, список устройств обновился:

```js
const devices = await getMidiDevices();   // [{ id, name }, ...]

dd.setItems(
  devices.map(d => ({ label: d.name, value: d.id })),
  { value: dd.value }                      // оставить текущий выбор, если он ещё есть
);
```

Если значения из `value` в новом списке нет, дропдаун станет «ничего не выбрано» (покажется `placeholder`).

Если дропдаун был раскрыт, `setItems` его закроет.

## Автосборка из HTML

```html
<div data-fdd
     data-items="Turn off|SMC-Mixer|MIDIIN2"
     data-index="1"
     data-direction="up"
     data-placeholder="Choose…"></div>

<script>
  const dropdowns = FDDropdown.auto();          // все [data-fdd] на странице
  // FDDropdown.auto(someElement) ищет только внутри someElement
</script>
```

`data-items` это либо список через `|`, либо JSON-массив, например `[{"label":"A","value":1}]`. Через атрибуты доступны `data-index`, `data-placeholder`, `data-direction`. Для остального создавай дропдаун из JS.

`FDDropdown.auto()` возвращает массив созданных экземпляров.

## Клавиатура

Фокус стоит на кнопке-шапке (Tab).

| Клавиша | Закрыт | Открыт |
|---|---|---|
| `↓` / `↑` | Открыть | Следующий / предыдущий пункт (недоступные пропускаются) |
| `Home` / `End` | нет | Первый / последний пункт |
| `Enter` / `Space` | Открыть | Выбрать подсвеченный пункт |
| `Esc` | нет | Закрыть без выбора |
| `Tab` | Обычный переход | Закрыть и перейти дальше |

В раскрытом виде клик по шеврону (правый верхний угол шапки) закрывает список без выбора. Клик вне дропдауна тоже закрывает. Одновременно открыт только один дропдаун на странице.

## Стили

Внешний вид настраивается CSS-переменными. Задавать их нужно на самом элементе `.fdd`, а не на контейнере. Для этого есть `className` и более специфичный селектор:

```js
new FDDropdown('#a', { items, className: 'accent' });
```

```css
.fdd.accent {
  --fdd-bg: #1b1f2a;
  --fdd-active: #2d3550;
  --fdd-radius: 10px;
}
```

Либо точечно из JS: `dd.root.style.setProperty('--fdd-bg', '#1b1f2a')`.

Простой селектор вроде `.accent { ... }` может проиграть стилям библиотеки, потому что она добавляет свой `<style>` при создании первого дропдауна.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `--fdd-bg` | `#232323` | Фон карточки |
| `--fdd-border` | `#343434` | Рамка |
| `--fdd-hover` | `#2e2e2e` | Подложка при наведении и навигации клавиатурой |
| `--fdd-active` | `#393939` | Подложка выбранного пункта |
| `--fdd-text` | `#e6e6e6` | Основной цвет текста |
| `--fdd-muted` | `#8c8c8c` | Цвет невыбранных пунктов, плейсхолдера и шеврона |
| `--fdd-radius` | `12px` | Скругление карточки |
| `--fdd-item-radius` | `8px` | Скругление подложки пункта |
| `--fdd-head` | `38px` | Высота шапки в закрытом виде |
| `--fdd-item-h` | `32px` | Высота одного пункта |
| `--fdd-gap` | `2px` | Расстояние между пунктами |
| `--fdd-pad` | `6px` | Отступ списка от краёв карточки со всех сторон |
| `--fdd-dur` | `.55s` | Длительность анимации |
| `--fdd-ease` | `cubic-bezier(.22,1,.36,1)` | Кривая анимации |

Размеры связаны между собой. Закрытая карточка имеет высоту `--fdd-head` плюс 2px рамки, а в закрытом виде выбранный пункт центрируется по высоте шапки. Если меняешь `--fdd-head` и `--fdd-item-h`, значения лучше подбирать так, чтобы разница была чётной, тогда текст не «подпрыгивает» на полпикселя.

| `.fdd-item` | Пункт |
| `.fdd-sel` | Выбранный пункт |

| `.fdd-kbd` | Пункт, подсвеченный стрелками |
| `.fdd-head` | Кнопка-шапка |
| `.fdd-chev` | Шеврон |
| `.fdd-ph` | Плейсхолдер |
| `.fdd-open` | На корне, когда список раскрыт |
| `.fdd-dir-up` | На корне, когда направление вверх |
| `.fdd-empty` | На корне, когда ничего не выбрано |

## Важные нюансы

- **Карточка накладывается поверх страницы** (`position: absolute`), поэтому раскрытие не сдвигает соседние элементы. Но если у какого-то родителя стоит `overflow: hidden` (или `auto`), раскрытый список обрежется. Дропдаун надо класть в контейнер без обрезки.
- У открытой карточки `z-index: 10`. Если на странице есть элементы выше, подними через `.fdd-card` или вынеси дропдаун из их контекста наложения.
- Пункты однострочные и фиксированной высоты. Длинный текст обрезается многоточием.
- Анимация не вызывает перерасчёта раскладки: пункты двигаются через `transform`, а карточка меняет только высоту.
- При `prefers-reduced-motion: reduce` анимации практически отключаются.

## Ограничения

- Нет прокрутки внутри списка: при очень большом числе пунктов (больше 10–12) карточка просто растёт, и список может не поместиться в окно
- Нет поиска и быстрого перехода по набранным буквам
- Нет мультивыбора и групп
- Нет сворачивания в нативный `<select>` на мобильных, всё рисуется самой библиотекой
